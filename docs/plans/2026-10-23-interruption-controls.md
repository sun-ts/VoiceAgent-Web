# 播报打断设置

Web 与手机端使用同一个设置组件和 SpeakerSession 判断逻辑。

- 总开关名称为“播报打断”，默认开启。关闭后，助手回复生成、待播及播放期间的语音不进入 ASR，不触发追问；开场白也遵守总开关。空闲时仍可正常提问。
- “仅同一说话人可打断”默认开启。关闭后不登记或比对声纹，仍遵守有效字数条件。
- “打断所需字数”默认 3，范围 1–50。统计 Unicode 汉字、字母和数字，不计标点和空格。开场白遵守同样的字数设置；尚无提问者时沿用现有开场白免声纹模式。
- 用户确认在开始检测前设置，启动中和检测中锁定。停止后解锁；点击开始前应用完整设置，模式变化会清理旧声纹及未完成请求，避免旧结果跨模式放行。
- 设置保留在当前页面内，停止再开始不丢失；刷新页面恢复默认值。手动文本提交不属于语音打断控制范围。

验证包含默认行为、禁用总开关时的开场白/正常回复、关闭声纹服务后的按字数打断、自定义字数、旧请求失效，以及两端 PCM/MP3 的设置锁定与停止后重启。
