# 设置卡片与说明

- 电脑与手机端已有设置统一使用 SettingsCard，统一标题栏、边框、圆角、内边距和表单控件。保留两端现有的设置范围；手机端仍使用嘈杂环境 VAD 预设。
- 所有设置项增加小问号；电脑悬停、键盘聚焦、手机点击可读说明。原来的常驻解释移入提示，去掉过时的固定“3 字、同一人”交互说明。提示应包含用途、范围、调大调小的影响与生效时机。
- 用户最后明确只设置下限，不设置上限。新增“音量筛选”卡片，默认启用，“允许降低 (dB)”默认 15，范围 0–60。以首次达到 VAD 人声阈值的音频帧作为参考，下次空闲语音起始音量不低于参考减去允许降低值；声音升高没有上限限制。
- 用户确认播报期间继续跳过音量限制；VAD、声纹与字数打断规则仍独立生效。关闭音量筛选不等于关闭 VAD，也不等于允许任何人打断。
- 音量值是 PCM 计算的相对值，未经声压校准。提示明确这一点，避免把它当作环境分贝仪。
- 音量与打断设置在开始前应用，启动和检测中锁定，停止后可修改；重启检测重置音量参考。
- 验证覆盖下限筛选、较大声音不被上限拦截、禁用、播报旁路、重置、两端设置传递与锁定、提示交互以及手机小屏滚动。
