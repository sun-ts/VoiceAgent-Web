# 登录后并发准备语音引擎

**Goal / 已确认需求：** 登录前只加载登录页必需资源；登录后按终端显示主页面，并发下载 ONNX、WASM、MJS；语音就绪后才开放开始检测。

**Architecture：** App 使用异步组件，Element Plus 随主页面注册；共享 VAD 加载器并发 fetch ONNX/WASM、modulepreload MJS 和动态导入 VAD。ONNX 通过共享模型加载器缓存响应，构建及开发预构建将 vad-web 的模型加载器接到同一缓存；避免使用 preload 等待 WASM 时的警告，也不依赖 HTTP 缓存复用。WASM 检查 HTTP 状态后通过 wasmBinary 交给 ONNX，避免重复下载。两端显示准备、失败重试和就绪状态；初始化期间退出页面须释放迟到的 VAD 实例。

**约束：** 保留工作区已有改动；不更改打断、ASR、TTS 逻辑；原 URL 保持不变以复用 Nginx 压缩协商；不引入新运行时依赖。

- [x] App 按需加载桌面/移动页面及 Element Plus，显示页面加载状态和失败重试入口。

**验证结果：** 生产构建及 10 项 Chromium 浏览器回归通过（含慢 WASM、禁用 HTTP 缓存、开发预构建下载复用）；移动端使用视口及 UA 模拟，尚未进行真实 iOS 验证。登录入口 JS 115.53 KB、CSS 8.35 KB（未压缩）；Element Plus 的大包提示仍存在，但只在登录后下载。针对 vad-web 0.0.30 未启动实例的 destroy 限制增加兼容释放；两端就绪后直接退出以及加载期间退出均验证 AudioContext 关闭。
